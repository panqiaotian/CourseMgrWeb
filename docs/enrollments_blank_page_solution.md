经过详细调查，课程报名页面显示空白的原因是：

### 1. 主要原因：数据库中没有课程报名记录
- `course_enrollments` 表存在且结构正确
- 但表中没有任何数据（0条记录）

### 2. 次要原因：模板渲染上下文问题
- `layout.html` 中的 `{{ csrf_token() }}` 需要在HTTP请求上下文中才能正常工作
- 这可能导致在某些情况下模板渲染失败
